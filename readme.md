# Dharamshala Places SQL Project

This project is a simple SQL database of tourist places in Dharamshala.

## Features

* Stores information about places like temples, treks, lakes, etc.
* Allows filtering based on:

  * Rating
  * Distance
  * Entry fee
* Includes queries to find:

  * Top rated places
  * Nearby locations
  * Budget-friendly spots

## Technologies Used

* SQL (MySQL)

## How to Run

1. Open SQL environment
2. Run `dharamshala_places.sql`
3. Execute queries to view results

## Purpose

Built to practice SQL queries using a real-world inspired dataset.
